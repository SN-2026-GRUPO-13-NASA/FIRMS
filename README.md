# 🛰️ NASA FIRMS - Sistema de Monitoramento de Focos de Incêndio

**Organização:** `SN-2026-GRUPO-13-NASA`  
**Projeto Supabase:** `FIRMS-DB`  
**Membro / Responsável:** Rian E. Carvalho (Grupo 13)

---

## 📌 Descrição do Projeto
Este projeto consiste em um pipeline automatizado de extração, tratamento e exibição de dados de focos de incêndio em tempo real disponibilizados pela API NASA FIRMS (VIIRS/MODIS). Os dados são processados a cada 6 horas por um workflow no **GitHub Actions**, armazenados no **Supabase** e exibidos no **GitHub Pages**.

---

## 🛠️ Tecnologias Utilizadas
- **Linguagens:** HTML5, CSS3, JavaScript (ES6+), Python 3.10, SQL
- **Banco de Dados:** PostgreSQL (Supabase)
- **CI/CD & Automação:** GitHub Actions
- **Hospedagem:** GitHub Pages
